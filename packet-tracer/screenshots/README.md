Project Screenshots

This folder contains screenshots documenting the Operation RouteStorm network simulation.

The screenshots will demonstrate:

- Complete three-router network topology
- Router interface configurations
- Static routing configuration
- Routing table verification using "show ip route"
- Interface status using "show ip interface brief"
- End-to-end connectivity tests using "ping"

These screenshots provide visual evidence of the network implementation and testing performed in Cisco Packet Tracer.
